HECTEE Staff Applications — GitHub Pages

FILES
- index.html: complete responsive website
- assets/hectee-icon.jpg: cropped Hectee server icon from the provided screenshot

PUBLISH ON GITHUB
1. Sign in to https://github.com
2. Create a new public repository named exactly: YOUR-USERNAME.github.io
   (replace YOUR-USERNAME with your GitHub username)
3. Upload index.html and the assets folder to the repository root.
4. Open Settings → Pages. Choose Deploy from a branch, select main and /(root), then Save.
5. Your site will be at https://YOUR-USERNAME.github.io

IMPORTANT SETUP
- In index.html, find HECTEE_INVITE_URL and replace https://discord.com with your real permanent Discord invite URL.
- This is a front-end demo. GitHub Pages is static hosting: it does not store or send applications, and the membership question is self-reported. For reliable member verification and application delivery, connect Discord OAuth2 with a secure backend or a Discord bot. Never put bot tokens or private keys in index.html.
